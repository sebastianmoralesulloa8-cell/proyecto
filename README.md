# Proyecto: Aventura Pixel

## Descripción
Aventura Pixel es un videojuego de plataformas en 2D donde el jugador controla a un héroe que debe superar niveles llenos de obstáculos, recolectar monedas y derrotar enemigos para salvar el reino.

## Objetivo
El objetivo del proyecto es crear un videojuego completo y funcional que demuestre el uso de programación, diseño de niveles y mecánicas de juego, además de servir como proyecto de aprendizaje en desarrollo de videojuegos.

## Autor
Estudiante de 4to de secundaria - Proyecto escolar

## Estado actual del proyecto
El proyecto se encuentra en desarrollo. Actualmente cuenta con el diseño de los primeros 3 niveles, la mecánica de movimiento del personaje y el sistema de puntos. Se planea agregar más niveles y efectos de sonido en versiones futuras.

## Controles del juego
- Flechas del teclado: mover al personaje
- Barra espaciadora: saltar
- Tecla E: interactuar con objetos
